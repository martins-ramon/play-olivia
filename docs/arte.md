# Arte da heroína

Criada com a ferramenta integrada image_gen a partir das três fotos fornecidas. Ilustração original, com preferência por rosa e atmosfera de casinha mágica com gatos. Fotografias originais ficam em assets/ e não são incluídas no aplicativo.

## Prompt inicial

Use case: illustration-story. Asset type: transparent full-body heroine illustration for an offline native iPad educational game for a five-year-old.
Input images: all three images are reference photographs of the same child, Olivia. Use ONLY the child's face/hair/general appearance as reference; do not include the photos, locations, other people, logos, or toys.
Primary request: create an adorable, beautifully illustrated storybook game avatar of this little girl, recognizable warm smile, brown eyes, straight dark brown shoulder-length hair, age-appropriate five-year-old child proportions. Full body, standing in an inviting happy pose with one hand waving. Pink cat-ear headband, dusty pink pinafore over light cream shirt, tiny heart patch, comfy pink sneakers. She loves pink and imaginative magical dollhouses with friendly cats. Make an original character, no franchise character. High-end children's book gouache meets soft 3D paper illustration, soft tactile shading, clean silhouette and expressive face, joyful gentle mood.
Composition: exactly ONE girl, entirely visible including feet and fingertips, centered with generous transparent space around silhouette. Actual transparent background. No scene, no text, no letters, no border, no floor shadow, no props covering face. Final game uses this art as a layered animated hero. Preserve reference resemblance while making a charming illustration.

## Refinamento de estilo

Use case: style-transfer. Edit target: the supplied image of Olivia wearing a pink cat headband and pink pinafore. Change the rendering style from a realistic photograph to a CLEARLY DRAWN, charming hand-painted children's storybook illustration. This must look like a professional 2D cartoon game character: oversized expressive drawn brown eyes, simplified rounded facial features, smooth painted dark brown hair shapes, visible gouache shading, softly outlined pastel pink clothing, cute simplified short child proportions. Keep the same recognizable girl, her pink cat ears, cream blouse, pink pinafore, shoes and waving pose. Full body including both feet and hand. IMPORTANT: fully remove ALL background and glow/halo, make the background truly transparent with clean silhouette. No photorealistic skin, no individual hair strand photography, no scene, no gradient backdrop, no text. Exactly one character.
